Edit performances on your MX

A performance is a stored setup of up to 16 voices with split, layer, arpeggio and mix settings. This guide covers reading them from the keyboard, changing the voices in each, and writing them back.

1. Set up

  1. Use Chrome or Edge on a computer. Firefox and Safari don't support the MIDI access the editor needs.
  2. Connect the MX to the computer with its USB TO HOST cable and switch the keyboard on.
  3. Open mx-performance-editor.html from your computer (double-click it) or from a localhost server. Pages opened from a normal web address over plain http are blocked from MIDI.
  4. On the keyboard, set Bulk Protect to off (in the Utility settings). While it is on, the keyboard ignores every write.
Close other MIDI software first. A DAW or another editor that has the MX's USB port open can stop the browser from receiving data.

2. Connect

  1. Click Connect MIDI in the top bar and allow the browser's MIDI permission prompt. It must include system exclusive access.
  2. Choose the MX in both drop-downs. It is picked automatically when its name contains "MX". The dot turns green when both ports are set.
  3. Check Dev#. It must match the device number set on the keyboard (default 1).

You can skip all of this and browse offline. Editing works without a keyboard, but reading, trying and writing need the connection.

3. Browse and read performances

The first screen lists all 128 performances (slots A01 to H16). Search matches the performance name, slot or any voice name. The Source column shows where each one came from:

TagMeaning
factory listBuilt from the Data List: name, mode, split point and the voices in parts 1, 2 and 10 only. An approximation, not what is stored in your keyboard.
from keyboardRead from your MX. Complete and accurate.
modifiedChanged here and not yet written to the keyboard.

Click Read all from keyboard once. It requests the 128 performances one at a time and takes about a minute. Do this before editing so you start from your real data. Everything is saved in the browser, so you only need to read again after changing things on the keyboard itself.

Click any row to open it. The screen shows the name, keyboard mode, split point, volume, arpeggio switch and tempo at the top, then one card per active part.

Add a voice

Click ＋ Add voice, search by name or category (AP, KB, ORG, GTR, BAS, STR, BRS, WND, LD, PAD, CMP, CP, DR, SFX, MFX, ETH) and click the voice. It takes the first free part.

Change a voice

Click Change voice on a part and pick another. Its volume, pan and range settings stay as they were.

Delete a voice

Click Remove. The part is switched off by setting its receive channel to off. The count shows how many of the 16 parts are in use.

Part settings

ControlWhat it does
Vol, PanPart level (0 to 127) and position (64 is centre).
Rev, ChoHow much of the part goes to the performance's reverb and chorus.
Note ≥ and ≤Lowest and highest MIDI note the part plays. Middle C is 60 on the MX, so C3 = 60 and C4 = 72. Hover a field to see the note name.
ShiftTranspose in semitones. 64 means no shift, 76 is one octave up.
ChThe MIDI channel the part receives on, counted from 0 (0 is channel 1). Parts normally use their own number.

Making a split

Set the keyboard mode to split and choose the split point (a note number, shown next to the field). Add a bass voice and a lead voice, then limit each with Note ≥ / ≤: for example bass 0 to 59 and lead 60 to 127. For a layer, set the mode to layer and leave both parts at the full range.

5. Create a new performance

  1. Pick the slot to use and open it. Copy to… duplicates an existing performance into another slot, which is the quickest way to start from something close.
  2. Or click Clear performance to empty the slot. It keeps the reverb, chorus and EQ settings that were in it and removes every voice.
  3. Type a name (up to 10 characters), set the mode, then use ＋ Add voice for each sound.
Effects on new performances. The editor can't read the keyboard's exact default reverb and chorus values, so a cleared performance keeps those of the performance it replaced. Starting from a copy of one you like is safer than starting empty.

6. Try it, then save it

  1. Audition sends the performance to the keyboard's edit buffer. Play the keyboard in performance mode to hear it. Nothing is stored yet, and selecting another performance on the keyboard discards it.
  2. Test note plays middle C on channel 1 if you want to hear it without touching the keys.
  3. Happy with it? Click Write to A01 (the label shows the slot). Confirm the prompt. This overwrites that slot on the keyboard.

Re-read from keyboard throws away your edits to that performance and loads what is stored.

7. Back up and share

  • Export .syx on a performance saves that one. Export all .syx on the list saves all 128. Do this before a big round of overwrites.
  • Import .syx loads performances from a file into consecutive slots starting at the number you enter. Imported ones are marked modified until you write them.
  • Reset library discards all local edits and goes back to the factory list. It doesn't touch the keyboard.

Troubleshooting

ProblemTry
Status says Web MIDI isn't supportedUse Chrome or Edge.
No MX in the port listsCheck the USB cable and power, close other MIDI programs, then reload the page and connect again.
Reading times outConfirm both ports are chosen and Dev# matches the keyboard.
Writes do nothingTurn Bulk Protect off on the keyboard.
Audition makes no sound changePut the keyboard in performance mode and make sure Local Control and the volume are up.
A voice shows as "Unknown voice"Its bank and program numbers aren't in the Data List. It still plays and can be kept or replaced.
