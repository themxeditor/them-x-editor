Edit performances on your MX

A performance is a stored setup of up to 16 voices with split, layer, arpeggio and mix settings. This guide covers reading them from the keyboard, changing the voices in each, and writing them back.

1. Set up

  1. Use Chrome or Edge on a computer. Firefox and Safari don't support the MIDI access the editor needs.
  2. Connect the MX to the computer with its USB TO HOST cable and switch the keyboard on.
  3. Open mx-performance-editor.html from your computer (double-click it) or from a localhost server. Pages opened from a normal web address over plain http are blocked from MIDI.
  4. On the keyboard, set Bulk Protect to off (in the Utility settings). While it is on, the keyboard ignores every write.
Close other MIDI software first. A DAW or another editor that has the MX's USB port open can stop the browser from receiving data.

2. Connect

  1. Click Connect MIDI in the top bar and allow the browser's MIDI permission prompt. It must include system exclusive access.
  2. Choose the MX in both drop-downs. It is picked automatically when its name contains "MX". The dot turns green when both ports are set.
  3. Check Dev#. It must match the device number set on the keyboard (default 1).

Two more settings sit next to the ports:

  • Follow (on by default) makes the keyboard switch to whichever performance you open here. Untick it to browse without touching the keyboard.
  • Ch is the MIDI channel the keyboard receives program changes on (default 1). It only matters for Follow.
  • Bulk interval is the pause the keyboard leaves between the SysEx messages it sends, from 0 to 900 ms. The editor reads the current value when you connect. Lower values make reading performances and voices much faster, so try 0 ms first. If data goes missing at 0, step up to 10 or 20 ms. The setting is stored in the keyboard.

Right after connecting, the editor reads the names of the 128 user voices in the background so they show by name everywhere. Names are remembered in the browser, so this is quick next time.

You can skip all of this and browse offline. Editing works without a keyboard, but reading, trying and writing need the connection.

3. Browse and read performances

The first screen lists all 128 performances (slots A01 to H16). Search matches the performance name, slot or any voice name. The Source column shows where each one came from:

TagMeaning
factory listBuilt from the Data List: name, mode, split point and the voices in parts 1, 2 and 10 only. An approximation, not what is stored in your keyboard.
from keyboardRead from your MX. Complete and accurate.
modifiedChanged here and not yet written to the keyboard.

Click Read all from keyboard once. It requests the 128 performances one at a time and takes about a minute. Do this before editing so you start from your real data. Everything is saved in the browser, so you only need to read again after changing things on the keyboard itself.

4. Add, change and remove voices

Click any row to open it. With Follow on, the keyboard switches to that performance too: it recalls the stored slot, or receives your unsaved edits in its edit buffer if you have changed it here. The ◀ ▶ buttons step through slots the same way. The screen shows the name, keyboard mode, split point, volume, arpeggio switch and tempo at the top, then one card per active part.

Add a voice

Click ＋ Add voice, search by name or category (AP, KB, ORG, GTR, BAS, STR, BRS, WND, LD, PAD, CMP, CP, DR, SFX, MFX, ETH) and click the voice. It takes the first free part.

Change a voice

Click Change voice on a part and pick another. Its volume, pan and range settings stay as they were.

Delete a voice

Click Remove. The part is switched off by setting its receive channel to off. The count shows how many of the 16 parts are in use.

The performance name, mode, split point, volume, arpeggio and tempo stay pinned under the top bar as you scroll through the parts.

Making a split

Set the keyboard mode to split and choose the split point (a note number, shown next to the field). Add a bass voice and a lead voice, then limit each with Note ≥ / ≤: for example bass 0 to 59 and lead 60 to 127. For a layer, set the mode to layer and leave both parts at the full range.

5. Create a new performance

  1. Pick the slot to use and open it. Copy to… duplicates an existing performance into another slot, which is the quickest way to start from something close.
  2. Or click Clear performance to empty the slot. It keeps the reverb, chorus and EQ settings that were in it and removes every voice.
  3. Type a name (up to 10 characters), set the mode, then use ＋ Add voice for each sound.
Effects on new performances. The editor can't read the keyboard's exact default reverb and chorus values, so a cleared performance keeps those of the performance it replaced. Starting from a copy of one you like is safer than starting empty.

6. Effects and EQ

Open a performance and choose the Effects & EQ tab. It has three panels that apply to the whole performance.

Reverb

Pick one of the reverb types, then adjust its parameters (reverb time, delay, filters and so on). Return level and pan set how loud the reverb is in the mix.

Chorus

Choose a chorus, delay, flanger, phaser or tempo-synced type. It has its own return, pan and a send into the reverb.

Master EQ

Five bands (low, low-mid, mid, high-mid, high) with gain, frequency and Q. The low and high bands can be shelving or peaking.

Values show in real units (seconds, milliseconds, Hz, dB) taken from the Data List's tables. Each part's own Rev and Cho sliders on the Voices tab set how much of that part goes to these effects.

New effect types start from neutral values. The Data List doesn't give the factory preset values, so after switching type, adjust the sound by ear. Re-reading a performance from the keyboard brings back its stored settings.

7. Voice editor

Each part card has an Edit voice button. In the voice picker, every voice has an Edit… button as well, so you can open a voice before choosing it. The editor loads the voice's real data from the keyboard, so you must be connected.

  • General: volume, key assign mode, micro tuning, portamento time mode and legato slope.
  • Controllers / LFO: the six controller assignments (source, destination, depth) and the common LFO.
  • Insertion effect: the voice's own effect with all its parameters.
  • Element 1 to 8: each element's wave, key range, amplitude and pitch envelopes, filter, filter envelope and LFO. Dimmed tabs are elements that are switched off.

The voice picker also has a USER category with all 128 user voices. They are listed as "User 001" and so on until their names are read; Read user voices in the picker re-reads them from the keyboard.

Two buttons at the top finish the job:

  • Try on part sends the edited voice to that part of the performance currently in the keyboard's edit buffer. Audition the performance first so it is loaded there.
  • Save as user voice… opens a list of all 128 user voice slots with their names. Filter it, press Refresh names if some show "name not read yet", click the slot to overwrite, and confirm with Save here. A line above the list tells you which voice you are about to replace. The voice is written there and the part is pointed at it. Preset voices can't be overwritten, so edits always become a user voice.

You still need to Write the performance afterwards so that it keeps pointing at the new user voice.

Drum kits

Drum kits open in their own editor from Edit voice or Edit… in the voice picker. It has four tabs: General (name, volume), Controllers, Insertion effect, and Keys (drum pads). In Keys, choose a key from C0 to C6 (a filled dot means a drum sound is assigned) and edit its wave, level, pan, reverb and chorus sends, amplitude envelope, pitch and filter. Play key sounds the key, and Copy settings to key… copies one key's settings to another. Try sends the kit to the keyboard, and Save as user drum kit… writes to one of the 8 user kit slots. Preset and GM kits can't be overwritten. The user kit slot and sending a kit to a part are untested on hardware.

Managing user voices

Press User voices… on the performance list. The table shows all 128 user voice slots with their name, a status (on keyboard, modified, name only or not read) and the performances that use each voice. Use Read from keyboard to fill it in.

  • Copy to… and Swap with… open a slot list showing each slot's name, status and which performances use it. Pick one and confirm.
  • Click a name to rename it. Edit opens the voice editor, and saving offers the same slot first.
  • More… has Rename, Copy to…, Swap with…, Export .syx, Write to keyboard and Re-read from keyboard.
  • Tick rows to export or write just those voices. With nothing ticked, Write modified writes every voice you changed.
  • Copies, swaps, renames and imports stay in the editor, marked modified, until you write them. Overwriting a voice that performances use asks you to confirm and lists them.
  • Filters show only modified voices, voices used by performances, or voices not read yet.

The Voices… button opens a screen listing every voice (presets, GM, drum kits and user voices) with search and a category filter. Edit… opens the voice editor. Copy to user slot… copies a normal voice into a user slot of your choice, staged until you write it.

Arpeggio and rhythm pattern

On a performance, the Arpeggio tab has the common arpeggio settings and one card per voice in use. Each card has six slots (SF1 to SF6). Click a slot to choose one of the 999 arpeggio types, searching by name or filtering by category. Tick Also set the performance tempo to adopt the type's original tempo. Below the slots are the part's playback, range, timing, random and offset settings. Turn the part's Arpeggio switch on to use it.

The Rhythm pattern tab lists the 208 patterns by category. Click one to select it, and set Auto key-on start if you want it. Audition or Write the performance to hear it.

8. Try it, then save it

  1. Audition sends the performance to the keyboard's edit buffer. Play the keyboard in performance mode to hear it. Nothing is stored yet, and selecting another performance on the keyboard discards it.
  2. Test note plays middle C on channel 1 if you want to hear it without touching the keys.
  3. Happy with it? Click Write to A01 (the label shows the slot). Confirm the prompt. This overwrites that slot on the keyboard.

Re-read from keyboard throws away your edits to that performance and loads what is stored.

9. Back up and share

  • Export .syx on a performance saves that one.
  • Export everything (.syx) on the list saves all 128 performances and every user voice the editor has read, in one file. Do this before a big round of overwrites. Performances you haven't read from the keyboard are factory-list approximations, and the editor asks whether to include them. Export performances only leaves the voices out.
  • Import .syx accepts one or several files containing performances, user voices or both. A file with many items goes into the slots named inside it. A file with a single performance or voice asks which slot to use. Preset and edit-buffer voice dumps are skipped because they can't be stored.
  • Imported items are marked modified and exist only in the editor until you press Write all modified to keyboard (or write a single performance). Writing a full set takes a few minutes. The keyboard needs Bulk Protect off.
  • Edit or pick an imported user voice without a keyboard connected: the editor uses its stored copy.
  • Reset library discards all local edits and goes back to the factory list. It doesn't touch the keyboard.

Troubleshooting

ProblemTry
Status says Web MIDI isn't supportedUse Chrome or Edge.
No MX in the port listsCheck the USB cable and power, close other MIDI programs, then reload the page and connect again.
Reading times outConfirm both ports are chosen and Dev# matches the keyboard.
Reading is very slowLower the Bulk interval in the top bar. At 900 ms the keyboard waits almost a second between messages.
The Bulk interval box is greyed outIt is only active while connected. Connect to the keyboard first.
Writes do nothingTurn Bulk Protect off on the keyboard.
Audition makes no sound changePut the keyboard in performance mode and make sure Local Control and the volume are up.
The keyboard doesn't follow the performance I selectCheck that Follow is ticked, the keyboard is in performance mode, and Ch matches the channel it receives program changes on.
User voices show as "User 001"Their names haven't been read yet. Connect, wait for the status bar to say the names were read, or use Read user voices in the picker.
A voice shows as "Unknown voice"Its bank and program numbers aren't in the Data List. It still plays and can be kept or replaced.
