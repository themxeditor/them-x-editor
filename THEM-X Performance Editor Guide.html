THEM-X Performance Editor

A performance is a stored setup of up to 16 voices with split, layer, effects, arpeggio and mix settings. This guide covers reading performances from your Yamaha MX49, MX61 or MX88, editing them and their voices, and writing them back.

Experimental software. Back up your keyboard first (section 11) and keep the backup on a USB drive or other safe storage. Nothing here has been verified on every keyboard and firmware. See About.

1. Set up

  1. Use Chrome or Edge on a computer. Firefox and Safari don't support the MIDI access the editor needs.
  2. Connect the keyboard to the computer with its USB TO HOST cable and switch it on.
  3. Open them-x-performance-editor.html from your computer (double-click it) or from a localhost server. Pages opened from a normal web address over plain http are blocked from MIDI. Keep this guide file in the same folder: the Guide button in the top bar opens it.
  4. On the keyboard, set Bulk Protect to off (in the Utility settings). While it is on, the keyboard ignores every write.
Close other MIDI software first. A DAW or another editor that has the keyboard's USB port open can stop the browser from receiving data.

2. Connect

  1. Click Connect MIDI in the top bar and allow the browser's MIDI permission prompt. It must include system exclusive access.
  2. Choose the MX in both port drop-downs. It is picked automatically when its name contains "MX". The dot turns green when both ports are set.
  3. Check Dev#. It must match the device number set on the keyboard (default 1).

Right after connecting, the editor reads the names of the 128 user voices in the background so they show by name everywhere. Names are remembered in the browser.

You can skip all of this and browse offline. Editing performances works without a keyboard, but reading, trying, writing and loading voice data need the connection.

The first screen lists all 128 performances (slots A01 to H16). Search matches the name, slot or any voice name. The Source column shows where each one came from:

Click Read all from keyboard once. It requests the 128 performances one at a time. Do this before editing so you start from your real data. Everything is saved in the browser, so you only need to read again after changing things on the keyboard itself.

4. The performance page

Click a row to open it. With Follow on, the keyboard switches to that performance too: it recalls the stored slot, or receives your unsaved edits in its edit buffer if you have changed it here. The whole top section stays pinned under the top bar as you scroll. It holds the breadcrumb and the buttons (◀ ▶ to step through slots, Audition, Write, Re-read, Test note, Export, Copy to…, Clear performance), then a card with the name, keyboard mode, split point, performance volume, arpeggio switch and tempo.

Below that are four tabs: Voices, Effects & EQ, Arpeggio and Rhythm pattern. The Voices tab has one card per active part.

Add a voice

Click ＋ Add voice, search by name or category (AP, KB, ORG, GTR, BAS, STR, BRS, WND, LD, PAD, CMP, CP, DR, SFX, MFX, ETH) and click the voice, then choose where it goes: the first free part, a specific free part, before or after an existing voice (the voices after it move down one part), or replace a voice. The button and the insertion-effect summary sit in the pinned panel under the name and tempo fields.

To move one voice, use the small ⌃ and ⌄ arrows above and below its number. To rearrange several, press Reorder (to the right of the insertion-effect summary). A panel lists the voices by number and name: drag them up or down, then press OK. The voices are renumbered 1, 2, 3… in the new order; each voice keeps its own channel and insertion-effect setting.

Change a voice

Click Change voice on a part and pick another. Its volume, pan and range settings stay as they were.

Edit or remove

Click the voice's name or Edit voice to open the voice editor (section 8). Remove switches the part off by setting its receive channel to off.

Part settings

The keyboard allows only 4 parts at a time to have it on, so the editor refuses a fifth and lists the four parts and voices that are using it. The name of the effect is shown in parentheses. It is read from the keyboard the first time (it says reading… or connect to read until then) and remembered. A performance read from the keyboard with more than 4 on shows a warning. The performance's reverb and chorus are system effects that every part can use.

Making a split or a layer

For a split, set the keyboard mode to split and choose the split point (a note number, shown next to the field). Add a bass voice and a lead voice, then limit each with Note ≥ / ≤: for example bass 0 to 59 and lead 60 to 127. For a layer, set the mode to layer, leave the parts at the full range and keep them on the same channel.

5. Create a new performance

  1. Open the slot to use. Copy to… opens a list of the 128 slots with their names and whether each has been read or modified. Pick one and press Copy here (or double-click it). This is the quickest way to start from something close.
  2. Or click Clear performance to empty the slot. It keeps the reverb, chorus and EQ settings that were in it and removes every voice.
  3. Type a name (up to 10 characters), set the mode, then use ＋ Add voice for each sound.
Effects on new performances. The editor can't read the keyboard's exact default reverb and chorus values, so a cleared performance keeps those of the performance it replaced. Starting from a copy of one you like is safer than starting empty.

6. Effects and EQ

Open a performance and choose the Effects & EQ tab. It has three panels that apply to the whole performance.

Reverb

Pick one of the reverb types, then adjust its parameters (reverb time, delay, filters and so on). Return level and pan set how loud the reverb is in the mix.

Chorus

Choose a chorus, delay, flanger, phaser or tempo-synced type. It has its own return, pan and a send into the reverb.

Master EQ

Five bands (low, low-mid, mid, high-mid, high) with gain, frequency and Q. The low and high bands can be shelving or peaking.

Values show in real units (seconds, milliseconds, Hz, dB) taken from the Data List's tables. Each part's own Rev and Cho sliders set how much of that part goes to these effects.

New effect types start from neutral values. The Data List doesn't give the factory preset values, so after switching type, adjust the sound by ear. Re-reading a performance from the keyboard brings back its stored settings.

7. Arpeggio and rhythm pattern

The Arpeggio tab has the common arpeggio settings (SF select, common switch, synchro quantize and offsets) and one card per voice in use. Each card has six slots (SF1 to SF6). Click a slot to open a list of the 999 arpeggio types, with search, a category filter and an Off choice. Tick Also set the performance tempo to adopt the type's original tempo. Below the slots are the part's playback, range, timing, random and offset settings. Turn the part's Arpeggio switch on to use it. The tempo and main arpeggio switch are also in the card at the top of the page.

The Rhythm pattern tab lists the 208 patterns by category, with search. Click one to select it, and set Auto key-on start if you want it. Audition or write the performance to hear it.

8. Voice editor

Click a voice's name or Edit voice on a part. In the voice picker and on the Voices screen, every voice has an Edit… button too. The editor loads the voice's real data from the keyboard, so you must be connected. User voices you have already read can be edited offline.

Normal voices

  • General: volume, key assign mode, micro tuning, portamento time mode and legato slope.
  • Controllers / LFO: the six controller assignments (source, destination, depth) and the common LFO.
  • Insertion effect: the voice's own effect with all its parameters.
  • Element 1 to 8: each element's wave, key range, amplitude and pitch envelopes, filter, filter envelope and LFO. Dimmed tabs are elements that are switched off.

Two buttons at the top finish the job:

  • Try on part sends the edited voice to that part of the performance currently in the keyboard's edit buffer. Audition the performance first so it is loaded there.
  • Save as user voice… opens a list of all 128 user voice slots with their names. Filter it, click the slot to overwrite, and confirm with Save here. A line above the list tells you which voice you are about to replace. Preset voices can't be overwritten, so edits to them always become a user voice.

You still need to Write the performance afterwards so that it keeps pointing at the new user voice.

Drum kits

Drum kits open in their own editor from the same buttons. It has four tabs: General (name, volume), Controllers, Insertion effect and Keys (drum pads). In Keys, choose a key from C0 to C6 (a filled dot means a drum sound is assigned) and edit its wave, level, pan, reverb and chorus sends, amplitude envelope, pitch and filter. Play key sounds the key. Copy settings to key… opens a list of the keys to copy to (the target keeps its own wave number). Try sends the kit to the keyboard, and Save as user drum kit… opens a list of the 8 user kit slots. Preset and GM kits can't be overwritten. The user kit slots and sending a kit to a part follow the Data List but are untested on hardware.

9. Managing voices

User voices…

Press User voices… on the performance list. The table shows all 128 user voice slots with their name, a status (on keyboard, modified, name only or not read) and the performances that use each voice. Each performance in the Used by column is a link that opens it. Use Read from keyboard to fill the table in.

  • Edit… opens the voice editor, and saving offers the same slot first. Click a name to rename it (a small dialog accepts up to 10 plain characters, since a name can't be a list).
  • More… has Rename, Copy to…, Swap with…, Export .syx, Write to keyboard and Re-read from keyboard. Copy and Swap open a list of slots showing each slot's name, status and which performances use it.
  • Safe user-voice writes. Before a user voice is written, the editor reads what is currently in that keyboard slot and keeps a backup. If it cannot read the slot it asks before overwriting. If you are about to replace a real voice with an empty "Initialize" voice it warns you explicitly. After writing, it reads the voice back and compares; a voice that does not match is retried and stays modified. More… shows Restore previous (backup) on any slot that has a backup; that puts the old voice back into the editor as modified so you can write it. Voice reads that arrive incomplete or from the wrong slot are rejected and retried, so a partial read can no longer turn into an "Initialize" voice.
  • Tick rows to export or write just those voices. With nothing ticked, Write modified writes every voice you changed.
  • Copies, swaps, renames and imports stay in the editor, marked modified, until you write them. Overwriting a voice that performances use asks you to confirm and lists them.
  • Filters show only modified voices, voices used by performances, or voices not read yet.

Voices…

The Voices… button lists every voice (presets, GM, drum kits and user voices) with search and a category filter. The list shows 300 voices at a time; use ⏮ First, ◀ Prev, Next ▶ and Last ⏭ above and below it to page through the rest. Each voice shows a Used by list of performances (as links). Edit… opens the voice editor. Copy to user slot… copies a normal voice into a user slot you choose from a list, staged until you write it. Both need a connection for voices that must be read from the keyboard.

The voice picker

Add voice and Change voice open a picker with all voices and a USER category. User voices are listed as "User 001" and so on until their names are read; Read user voices re-reads them from the keyboard.

10. Try it, then save it

  1. Audition sends the performance to the keyboard's edit buffer. Play the keyboard in performance mode to hear it. Nothing is stored yet, and selecting another performance on the keyboard discards it.
  2. Test note plays middle C on channel 1 if you want to hear it without touching the keys.
  3. Happy with it? Click Write to A01 (the label shows the slot). Confirm the prompt. This overwrites that slot on the keyboard.

Checks the editor makes for you

  • Before sending (Audition or Write), each part's voice is checked. You are warned about a part that points to an invalid bank, a user voice that is empty on the keyboard (the part would show "Initialize"), a user voice you changed here but have not written yet, a voice that isn't in the voice list, or more than 4 voice insertion effects. For a changed user voice the dialog offers to write it first, which is the usual cause of a part showing "Initialize".
  • After sending, the editor reads the performance back and compares its name and every part's voice. If the keyboard doesn't match it sends again, more slowly, up to 3 times, and tells you if it still differs. If the keyboard doesn't answer the check, it says the write could not be verified.
  • When reading, a performance with missing blocks (a dropped transfer) is not accepted. The editor retries, and reports the read as failed if it stays incomplete.
  • Connection lost: if the USB connection drops, the editor tells you, stops any transfer in progress, and reminds you after reconnecting that the keyboard may differ from the editor.
  • Check keyboard on a performance reads that slot back and lists any differences, so you can keep your copy or take the keyboard's.

Re-read from keyboard throws away your edits to that performance and loads what is stored.

11. Back up and share

  • Export .syx on a performance saves that one.
  • Export everything (.syx) on the list saves all 128 performances and every user voice the editor has read, in one file. Do this before a big round of overwrites and keep a copy on a USB drive. Performances you haven't read from the keyboard are factory-list approximations, and the editor asks whether to include them. Export performances only leaves the voices out.
  • Import .syx accepts one or several files containing performances, user voices or both. A file with many items goes into the slots named inside it. A file with a single performance or voice opens a slot list to choose where it goes. Preset and edit-buffer voice dumps are skipped because they can't be stored.
  • Imported items are marked modified and exist only in the editor until you press Write all modified to keyboard (or write a single performance). Writing a full set takes a few minutes. The keyboard needs Bulk Protect off.
